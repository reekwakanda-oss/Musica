      What happens to your audio

      1. 01DecodeYour file — or the YouTube audio — becomes mono 22 050 Hz WAV.
      2. 02Strip drumsDemucs separates the stems and drops percussion, so transients stop inventing notes.
      3. 03Detect pitchSpotify's Basic Pitch reads onsets and sustain into discrete note events.
      4. 04Play it backThe same note list drives this roll, the keys, and the .mid you download.

      Powered by Spotify's Basic Pitch, Demucs, and Tone.js. Nothing is stored between visits.
